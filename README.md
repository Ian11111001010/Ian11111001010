# Калькулятор фасадов по фото (MVP)

Простой веб-MVP, где можно:
- загрузить фото фасада;
- задать реальные габариты стороны (ширина/высота);
- руками обвести контур фасада;
- добавить вырезы (окна/двери/прочие исключения);
- получить чистую площадь;
- рассчитать количество металлокассет и предварительную стоимость вентфасада;
- выгрузить **редактируемый чертеж стороны** в `SVG` и `DXF`.

---

## 🚀 Локальный запуск

```bash
make run
```

Если `make` нет:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://localhost:8000`.

---

## 📦 Деплой на VPS через Docker

```bash
make docker-up
```

Если без Makefile:

```bash
docker compose up -d --build
```

После этого приложение доступно по `http://IP_СЕРВЕРА:8080`.

Остановить:

```bash
make docker-down
```

## 🧭 Как пользоваться

1. Загрузите фото фасада.
2. Введите ширину и высоту стороны в метрах.
3. В режиме **Контур фасада** поставьте точки по периметру и нажмите **Завершить полигон**.
4. В режиме **Вырез (окно/дверь)** добавьте исключения.
5. Чтобы увидеть «чистый проектный вид», нажмите **Режим "чертеж"** (фото-подложка скрывается).
6. Нажмите:
   - **Экспорт SVG** — редактируемый векторный чертеж,
   - **Экспорт DXF** — для CAD (AutoCAD и совместимые),
   - **Экспорт JSON** — для повторной загрузки/интеграций.

---

## Что уходит в экспорт

- `SVG`: контур фасада + все вырезы в метрах (удобно для быстрых правок и согласований).
- `DXF`: полилинии в мм, слои:
  - `FACADE`
  - `EXCLUSION_1`, `EXCLUSION_2`, ...

---

## Формулы

- Чистая площадь: `S_net = S_facade - Σ(S_cutout)`
- Кассеты: `N = ceil((S_net * (1 + reserve/100)) / S_cassette_useful)`
- Стоимость:

```text
Cost_total =
  N * Price_cassette +
  S_net * Price_subsystem_m2 +
  S_net * Price_install_m2 +
  Extra_costs
```

---

## Ограничения текущего MVP

- Масштаб считается от введенных ширины/высоты и размеров холста (без перспективной коррекции).
- Для высокой точности на косых фото следующий этап — гомография/перспективная коррекция.
