# Калькулятор фасадов по фото (MVP)

Простой веб-MVP, где можно:
- загрузить фото фасада;
- задать реальные габариты стороны (ширина/высота);
- руками обвести контур фасада;
- добавить вырезы (окна/двери/прочие исключения);
- получить чистую площадь;
- рассчитать количество металлокассет и предварительную стоимость вентфасада.

---

## 🚀 Самый простой вариант (без деплоя, прямо сейчас)

### Шаг 1
Откройте терминал в папке проекта.

### Шаг 2
Запустите:

```bash
make run
```

Если `make` нет, используйте:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

### Шаг 3
Откройте в браузере:

- `http://localhost:8000`

Готово — можно пользоваться.

---

## 📦 Как задеплоить на сервер (Docker, 1 команда)

Подходит, если у вас VPS/сервер с Docker.

### Шаг 1
Скопируйте проект на сервер.

### Шаг 2
Запустите:

```bash
make docker-up
```

или напрямую:

```bash
docker compose up -d --build
```

### Шаг 3
Откройте:

- `http://IP_СЕРВЕРА:8080`

### Остановить:

```bash
make docker-down
```

## 🌍 Публичный деплой без сервера (Netlify, проще всего)

Если нужен публичный URL без администрирования сервера:

1. Зарегистрируйтесь в Netlify.
2. Нажмите **Add new site → Deploy manually**.
3. Перетащите папку проекта (или только `index.html`) в окно загрузки.
4. Получите ссылку вида `https://....netlify.app`.

Для этого проекта backend не нужен, поэтому Netlify подходит идеально.

## 🧭 Как пользоваться приложением

1. Загрузите фото фасада.
2. Введите ширину и высоту стороны в метрах.
3. В режиме **Контур фасада** поставьте точки по периметру и нажмите **Завершить полигон**.
4. Переключитесь в режим **Вырез (окно/дверь)** и добавьте исключения.
5. Ниже автоматически обновятся:
   - площадь фасада,
   - площадь вырезов,
   - чистая площадь,
   - количество кассет с запасом,
   - предварительная стоимость.

---

## Формулы

- Чистая площадь: `S_net = S_facade - Σ(S_cutout)`
- Кассеты: `N = ceil((S_net * (1 + reserve/100)) / S_cassette_useful)`
- Стоимость:

```text
Cost_total =
  N * Price_cassette +
  S_net * Price_subsystem_m2 +
  S_net * Price_install_m2 +
  Extra_costs
```

---

## Ограничения текущего MVP

- Масштаб считается от введенных ширины/высоты и размеров холста (без перспективной коррекции).
- Для реальных объектов с сильной перспективой нужно добавлять калибровку/гомографию (следующий шаг).
